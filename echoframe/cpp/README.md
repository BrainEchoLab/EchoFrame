# echoframe/cpp

This directory contains the core C/C++ code for the EchoFrame project, which handles the heavy computational tasks, including CUDA-accelerated processing, that interface with MATLAB via mex functions.

## Overview

The `echoframe/cpp/` directory is structured into several subdirectories, each focusing on a specific aspect of the project:

- **src/**: The main source directory where all the core functionalities are implemented. This includes the primary beamforming algorithms, CUDA utilities, and Fourier filtering techniques.

- **libs/**: Contains external libraries and submodules that support the core functionalities. (Detailed descriptions are provided within this directory's README.)

For more detailed information about the files and classes within each subdirectory, please refer to the respective README files within those directories.

## Further Documentation

Detailed descriptions and usage instructions for each component can be found in the README files within `src/` and its subdirectories. Users are encouraged to explore these directories for more specific guidance on working with the codebase.
